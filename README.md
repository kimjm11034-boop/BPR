# BPR (Badminton Player Record)

복식 배드민턴 경기를 빠르게 기록하고, 개인별 승률과 파트너 조합별 전적을 누적해서 확인하는 앱입니다.

- 웹: [BPR 실시간 기록 앱](https://bpr-badminton.kimjm11034.chatgpt.site)
- 모바일: Capacitor 기반 Android APK
- 저장 방식: 모바일은 오프라인 우선, 컴퓨터 전송이 필요할 때만 Supabase로 수동 동기화

## 주요 기능

- 경기 날짜와 오늘 참여할 선수 명단 등록
- 선수별 고유 ID를 사용한 중복 이름 지원 (동명이인도 서로 다른 선수로 관리)
- 복식 2:2 경기 입력과 경기별 승리팀 선택
- 파트너가 바뀌어도 개인별 누적 경기 수·승·패·승률 계산
- 파트너 조합별 경기 수·승·패·승률 계산
- 오늘 경기 기록 초기화 (전체 누적 기록과 순위표는 유지)
- 전체 경기 기록에서 실수로 입력한 경기 삭제
  - 삭제 전 확인창 표시
  - 개인 순위와 파트너 조합 순위에서 즉시 제외
  - 웹은 Supabase에 취소 상태로 보관해 감사 기록 유지
- 운영자 이메일 로그인 없이 모바일에서 즉시 기록
- 설정 화면의 `컴퓨터로 기록 보내기`에서 이메일 인증 후 기록 동기화

## 사용 방법

### 1. 홈 — 경기 준비

1. 경기 날짜를 선택합니다.
2. 선수 이름을 입력하고 `등록`을 누릅니다.
3. 등록된 선수 목록에서 최근 전적과 승률을 확인합니다.
4. 선수를 명단에서 제외하려면 휴지통 버튼을 누릅니다. 선수의 기존 경기 기록은 삭제되지 않습니다.

### 2. 경기 입력

1. 하단 메뉴에서 `경기입력`을 선택합니다.
2. 등록된 선수 중 네 명을 A팀 두 명, B팀 두 명으로 선택합니다.
3. 승리한 팀을 선택하고 `경기 기록 저장`을 누릅니다.
4. 같은 화면의 `오늘 경기 기록`에서 당일 입력 내역을 확인합니다.

### 3. 전체 기록·순위표

- `전체기록`: 누적 경기 기록을 최신순으로 확인합니다.
- 잘못 입력한 경기는 해당 행의 휴지통 버튼 → 확인을 눌러 삭제합니다.
- `순위표`: `개인 순위`와 `파트너 조합` 탭을 전환합니다. 승률이 높은 순서로 정렬됩니다.

### 4. 컴퓨터로 기록 보내기

모바일 기록은 먼저 핸드폰에 저장됩니다. 컴퓨터에서 확인하려면:

1. `설정` → `컴퓨터로 기록 보내기`를 누릅니다.
2. 운영자 이메일을 입력하고 인증 메일의 링크를 누릅니다.
3. 선수·경기·삭제(취소) 내역이 Supabase에 동기화됩니다.

앱을 시작하거나 경기 기록을 저장할 때는 이메일 인증이 필요하지 않습니다.

## 설치

### Android APK

1. `BPR-Android-설치패키지.zip`을 휴대폰에 다운로드합니다.
2. 압축을 풀고 `BPR-Android.apk`를 실행합니다.
3. Android에서 요청하면 파일 관리자/브라우저의 앱 설치 권한을 허용합니다.

이 APK는 직접 설치용 디버그 패키지이며 Google Play 배포용 서명 APK가 아닙니다. iPhone에서는 사용할 수 없습니다.

## 데이터 정책

- 선수 삭제는 명단에서만 제외하며 기존 누적 전적은 보존합니다.
- 오늘 경기 초기화는 오늘 화면의 목록만 비우며 전체 누적 기록은 보존합니다.
- 전체 경기 삭제는 복구 버튼이 없는 작업이므로 확인창을 거친 뒤 실행합니다.
- 모바일의 로컬 기록은 네트워크가 끊겨도 계속 사용할 수 있습니다.
- 같은 운영자 계정으로 수동 동기화할 때만 다른 기기·웹과 기록을 공유합니다.

## 개발 환경

```bash
npm install
npm run dev
```

검증 명령:

```bash
npm run typecheck
node --experimental-strip-types --test test/*.test.ts
npm run build -- --webpack
```

Android 패키지 생성:

```bash
npx cap sync android
cd android
gradlew.bat assembleDebug
```

필수 환경 변수는 `.env.example`을 참고하세요. Supabase의 service-role 키는 브라우저나 APK에 포함하지 않습니다.
